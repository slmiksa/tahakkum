# قاعدة البيانات والدوال

هذا الجزء يعمل على Supabase ولا يُرفع إلى سيرفرك.

- `supabase/migrations`: الجداول والصلاحيات.
- `supabase/functions`: الإصدار (`issue-batch`)، والتفعيل (`activate`)، والتجديد (`refresh`).
- `tools/setup.mjs`: يربط البرنامج واللوحة بمشروع Supabase.
- `secrets`: مفتاح توقيع الرخص. لا يُرفع ولا يُشارك أبداً، واحفظ منه نسخة احتياطية آمنة. إذا ضاع فلن تستطيع تجديد الرخص القائمة، وإذا تسرّب فسيستطيع أي شخص إصدار رخص صالحة.
- `secrets/functions.env`: فيه أيضاً مفتاح تشفير الأكواد المحفوظة `CODES_KEY`. احفظ منه نسخة احتياطية آمنة: إذا ضاع فلن تستطيع تصدير الأكواد الصادرة به مرة أخرى، مع بقائها صالحة للتفعيل.

## النشر

الأوامر من داخل هذا المجلد. على ويندوز استخدم `npx.cmd` إذا كان تشغيل ملفات PowerShell ممنوعاً.

```bash
npx supabase login
```

```bash
npx supabase link --project-ref PROJECT_REF
```

ثم انشر كل شيء بأمر واحد على ويندوز:

```bash
.\tools\deploy.cmd
```

لتقييد إصدار الأكواد بنطاق لوحتك فقط، أضف `DASHBOARD_ORIGIN=https://your-domain` إلى `secrets/functions.env` وأعد أمر `secrets set`.

## حساب المدير

من لوحة Supabase، قسم Authentication:

1. عطّل التسجيل العام (Allow new users to sign up).
2. أضف مستخدماً ببريدك وكلمة مرور قوية، وانسخ معرّفه (User UID).

ثم نفّذ في SQL Editor بعد وضع المعرّف:

```sql
insert into public.admins (user_id) values ('USER_ID');
```

## تصدير الأكواد مرة أخرى

من صفحة الدفعات، زر "تصدير": ملف فيه الأكواد وحالة كل كود وملخص المستخدم والمتبقي، وتُسجَّل كل عملية تصدير. الأكواد محفوظة مشفّرة، ولا يقرؤها من يصل إلى قاعدة البيانات وحدها. والدفعات الصادرة قبل هذه الميزة تصدّر حالتها وآخر 4 أحرف من كل كود فقط.

## توزيع الأكواد على الأجهزة

- يدوياً: يدخل الموظف الكود من زر "تفعيل البرنامج".
- عبر قسم IT: `Tahakkum.exe /activate TKM-XXXXX-XXXXX-XXXXX-XXXXX` (رمز الخروج 0 يعني نجاح التفعيل).

يحتاج التفعيل والتجديد إلى الوصول إلى `*.supabase.co`.

## كيف يتصرف البرنامج

- بعد التفعيل يعمل دون إنترنت حتى تاريخ الانتهاء.
- عند توفر الاتصال يحدّث الرخصة مرة يومياً، فيصله التمديد أو الإلغاء أو فك الارتباط.
- الجهاز غير المتصل لا يعلم بإلغاء رخصته، فتبقى صالحة عليه حتى يتصل أو تنتهي مدتها.
- عند الانتهاء تُمنع الجلسات الجديدة، وتكمل الجلسة الجارية.

## الاختبار

```bash
npm test
```

يشغّل قاعدة البيانات الفعلية على PGlite. ولاختبار البرنامج مقابلها: `client-program\tests\LicenseTest.cs`. ولرؤية اللوحة ببيانات تجريبية: `node tests/dashboard-preview.ts` ثم افتح `http://127.0.0.1:47890` (كلمة المرور `demo`، ورمز التحقق `123456`).
