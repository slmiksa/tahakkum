# خادم الاتصال

يعطي كل جهاز معرّفاً ثابتاً، ويمرر البيانات بين جهازين خارج نفس الشبكة. تشفير الجلسة يبقى بين الجهازين، فالخادم لا يرى الشاشة ولا كلمة السر. ولا يقبل إلا الأجهزة التي لديها رخصة سارية.

## التثبيت

يعمل على أنظمة عائلة Debian (Ubuntu وDebian وKali). السكربت جاهز في `release\tahakkum-relay-install.sh`، وليس فيه أي مفتاح سري.

من ويندوز، انسخه إلى السيرفر:

```bash
scp release\tahakkum-relay-install.sh root@SERVER_IP:/root/
```

ثم على السيرفر:

```bash
bash /root/tahakkum-relay-install.sh
```

المنفذ الافتراضي 443، لأن شبكات الشركات تسمح به غالباً. لاستخدام منفذ آخر أضف رقمه في نهاية الأمر.

يمكن إعادة تشغيل السكربت بأمان، فهو يحتفظ بالشهادة، وتبقى نسخ البرنامج الحالية تثق بالخادم.

## إدارته على السيرفر

```bash
systemctl status tahakkum-relay
```

```bash
journalctl -u tahakkum-relay -f
```

## ملفات مهمة

- `/etc/tahakkum-relay`: شهادة الخادم. إذا ضاعت أو تغيرت فيجب إعادة بناء البرنامج بالبصمة الجديدة.
- `/var/lib/tahakkum-relay/ids.txt`: معرّفات الأجهزة. انسخها احتياطياً، فبدونها يحصل كل جهاز على معرّف جديد.

## نقله إلى سيرفر آخر

انسخ المجلدين السابقين إلى السيرفر الجديد قبل تشغيل السكربت. وإذا تغير عنوان IP فيلزم بناء البرنامج بالعنوان الجديد، أو وضع العنوان في `%ProgramData%\Tahakkum\server.txt` على كل جهاز.
