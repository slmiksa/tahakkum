# تحكّم: دليل المشروع

| المجلد | ما هو | أين يعمل |
|---|---|---|
| `client-program` | **برنامج العميل** الذي يُثبَّت على أجهزة الشركات | أجهزة العملاء |
| `dashboard` | **لوحة التحكم** لإصدار الأكواد وإدارتها | سيرفرك |
| `relay-server` | **خادم الاتصال** للاتصال عبر الإنترنت بالمعرّف | سيرفرك (خادم Linux) |
| `supabase-backend` | **قاعدة البيانات والدوال**، ومفتاح توقيع الرخص | Supabase، ولا يُرفع إلى سيرفرك |
| `release` | **الملفات الجاهزة للتسليم** | تأخذها من هنا |
| `brand` | **الهوية الأصلية:** الشعار والألوان | مرجع للتصميم |

## الملفات الجاهزة

- `release\tahakkum-dashboard.zip`: ارفعه إلى سيرفرك، والتعليمات داخله في `README.md`.
- `release\tahakkum-client.zip`: أعطه للشركات مع ملف الأكواد.

## كيف تعمل الأجزاء معاً

1. تدخل إلى **لوحة التحكم** وتصدر أكواداً، فتُحفظ بصماتها في **Supabase** وينزل لك ملف الأكواد.
2. تعطي الشركة **برنامج العميل** وملف الأكواد.
3. يفعّل الموظف البرنامج بكود، فيتصل البرنامج بـ **Supabase** ويحصل على رخصة موقّعة مرتبطة بجهازه.
4. للاتصال خارج الشبكة يمر الاتصال عبر **خادم الاتصال**، أما داخل الشبكة فمباشرة.

## مهم

`supabase-backend\secrets` فيه مفتاح توقيع الرخص. لا ترفعه إلى سيرفرك ولا إلى GitHub، واحفظ منه نسخة احتياطية آمنة.
